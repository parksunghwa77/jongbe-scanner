📊 익일 개별주 시초가 시나리오 · 시험용

⚠️ 이 계산은 예측 모델이 아닌 가정값 비교 기능입니다. 아래 시장 수치와 계수는 자동 수집·통계 추정된 값이 아닙니다. 현재가나 미래 가격을 보증하지 않으며 실제 매매 근거로 사용하지 마세요.

한국 장 마감 후의 야간 변동 정보를 동일한 시간 기준으로 입력하세요. 나스닥은 나스닥100 선물(NQ), 한국 야선은 코스피200 선물입니다. 미국채 10년물은 금리 수준(%)이 아니라 전 관찰 시점 대비 변화(bp)입니다. 수치가 없으면 0 대신 빈칸으로 남겨 두세요.

계산 방식: 최근 확정 종가 × (1 + 예시 변동률/100). 예시 변동률은 시장요인 변화를 임의 가중합한 값이며 과거 학습·상관관계 검증·확률 계산이 아닙니다. SOX와 나스닥 선물은 움직임이 겹쳐 실제 회귀 모델에서 중복 반영 방지가 필요합니다. 향후 실제 예측을 위해서는 종목별 이력, 야간 지표 이력, 발표시각 일치 및 시간순 백테스트가 필수입니다.

보안: NH API 키·비밀키·계좌·주문 기능 없음. 기존 GitHub Pages가 게시한 공개 확정 일봉 파일만 읽습니다. 거래정지·상폐·결측 자료의 정확성은 원본 품질에 의존합니다. 데이터 지연 또는 차트 일부 로드 실패 시 검색 결과는 불완전할 수 있습니다.
